## 四、没写进去的（有意为之）

- **Spring AOP / 自定义注解**：landray 全库 `@Aspect` / `@Around` / `MethodInterceptor` / `HandlerInterceptor` **0 命中**，没有落点，只保留在"了解"层级，不单列。
- **MQ / Spring Cloud / 分库分表 / 分布式事务**：同理无落点，不做。
- **Spring Boot 不进项目经历**：那 8 个工程一个 `pom.xml` 都没有，挂上去问一句打包方式就崩。只在技能栏和概述里保留。
