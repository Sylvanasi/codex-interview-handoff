## 一、三条定稿

**第 1 条（原来是第 3 条，提到最前并扩写）**

改前：
> · 负责单点登录侧改造：基于 **IDaaS OAuth 过滤器**拦截未登录请求，完成票据校验与本地会话建立。

改后：
> · 负责 **IDaaS 单点登录（OAuth2 授权码）对接**：基于**过滤器**拦截未登录请求，302 跳转 IDaaS 授权端点并携带 state 防 CSRF；用户认证后回跳带 code，由**后端**用 code + client_secret 换取 token 并取回用户身份，完成 IDaaS 账号到 OA 本地账号的**映射**与本地会话建立；回调地址走**白名单**校验，票据**一次性消费**防重放

**第 2 条（保持 v12 原文）**

> · 负责 OA 待办与钉钉工作台集成：基于**钉钉开放平台待办推送**与**审批完成状态回调**，实现待办推送、点击跳转 OA 原审批表单、审批完成后回调同步 OA，解决用户在钉钉内无法处理 OA 审批的问题。

**第 3 条（只删掉末尾的日均数字）**

改后：
> · 基于**幂等键校验**避免同一待办重复推送，降低钉钉侧重复待办与用户投诉。

## 二、改动意图

- 顺序调成 **SSO → 钉钉集成 → 幂等**：把你自评最熟的单点登录放到第一条，面试官第一眼看到的就是你最能展开的那块。
- SSO 那条从一句话扩到六个要点：授权码流程、state 防 CSRF、后端换取（凭证不外泄）、账号映射、回调白名单、票据一次性消费。这些都在你自己的 `SSO单点登录-原理与面试话术.md` 里，属于要练熟的范围。
- 幂等那条**不再重复**技能栏「缓存与 Redis」里已经写过的 SETNX / TTL 措辞——技术手段留给技能栏讲，项目里只讲业务上防了什么事。
